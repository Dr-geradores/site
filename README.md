# DR Geradores Gestão

Protótipo móvel para orçamentos, agenda, contratos, checklist e controle financeiro.

## Executar localmente

Abra um servidor estático na pasta `dist` e acesse o endereço exibido no navegador.

Os dados desta primeira versão ficam no `localStorage` do navegador. A próxima etapa é substituir esse armazenamento pelo Firebase Authentication, Firestore e Storage.

## Estrutura

- `dist/index.html`: estrutura principal do aplicativo
- `dist/styles.css`: identidade visual responsiva
- `dist/app.js`: cadastros, orçamento em etapas e regras financeiras
- `dist/assets`: logos e fotos da DR Geradores
